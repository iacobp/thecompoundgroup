# The Compound Group — Parent Site

Minimal holdco site showcasing the portfolio of consumer health brands.

## Stack
- Next.js 15 (App Router)
- Tailwind CSS 3
- TypeScript
- Instrument Serif + Inter (Google Fonts)

## Design
- Function Health-inspired editorial design
- Warm palette: cream `#F4F1EB`, near-black `#1C1C1A`, deep sage `#3B5D4F` accent
- Quiet parent brand, loud portfolio brands
- Single-page architecture: Hero → Portfolio → Approach → Contact

## Run
```bash
npm install
npm run dev
```

## Deploy
GitHub → Vercel auto-deploy. Point domain `thecompound.group` at Vercel project.
